# Wasabi 主页

这是一个部署在 GitHub Pages 上的个人主页 / 常用网址导航站，用来集中整理我日常使用的网站、工具和资料入口。

项目地址：[https://github.com/wasabihu/wasabihu.github.io](https://github.com/wasabihu/wasabihu.github.io)

页面以静态方式运行，打开后会按分类展示收藏链接，并支持在浏览器里直接维护数据。它更像是一个长期自用的个人起始页，而不是通用的前端脚手架项目。

## 功能概览

- 分类展示常用链接，按顺序组织不同主题内容
- 使用两组标签页切分页面内容，方便收纳不同类型的网站入口
- 支持新增分类、新增链接、编辑分类、编辑链接、删除分类、删除链接
- 支持将当前修改保存到浏览器 `localStorage`
- 支持把当前数据导出为新的 JS 数据文件
- 支持一键清除本地存储，恢复到默认数据状态

## 技术实现

这个项目目前是纯静态站点，核心页面和数据都放在 `docs/` 目录下。

- 页面入口：`docs/index.html`
- 页面逻辑：`docs/index.js`
- 页面样式：`docs/style.css`
- 默认数据：`docs/data.js`
- 数据持久化与导出：`docs/dataManager.js`

页面主要依赖以下前端库：

- `jQuery`
- `jQuery UI`
- `Notyf`

当前仓库内没有发现 `package.json`、构建脚本或前端打包配置，所以它不是依赖构建流程运行的项目，直接以静态文件形式即可访问和维护。

## 数据机制

项目的数据来源分为两层：

1. 默认数据来自 `docs/data.js`
2. 运行时的修改会保存到浏览器 `localStorage`

页面加载时会优先读取本地缓存；如果本地没有可用数据，才会回退到 `docs/data.js` 中的默认内容，并写入本地存储。

当前数据结构约定如下：

### `initialCategories`

分类数组，每个分类对象包含以下字段：

- `id`：分类 ID
- `name`：分类名称
- `seq`：排序值
- `page`：所属标签页，例如 `fragment-1`

### `initialLinks`

以分类名为键的链接对象，每个链接项包含以下字段：

- `id`：链接 ID
- `href`：目标网址
- `title`：补充说明或提示信息
- `text`：页面显示名称
- `seq`：排序值

## 如何使用

如果你只是访问主页，直接打开线上页面即可。

如果你要本地查看或维护这个项目，可以直接打开 `docs/index.html`。项目没有强依赖构建工具，静态文件即可运行。

页面顶部提供以下几个主要操作按钮：

- `新增分類`
- `新增連結`
- `匯出資料 (JS)`
- `清除本地存储`

双击分类标题可以编辑分类，双击某个分类里的链接区域可以进入该分类下的链接编辑流程。

## 目录说明

### `docs/index.html`

定义页面结构、顶部操作按钮、两组标签页和编辑弹窗，是站点的主入口。

### `docs/index.js`

负责页面初始化、标签页渲染、链接生成、分类与链接的增删改逻辑，以及弹窗交互和事件绑定。

### `docs/style.css`

定义整站视觉风格，当前是偏霓虹风格的深色静态主页界面，并包含移动端适配。

### `docs/data.js`

保存默认的分类和链接数据，是站点的初始内容来源。

### `docs/dataManager.js`

负责从 `localStorage` 加载数据、保存数据，以及把当前内容导出成新的 JS 文件。

## 维护提示

- 如果要修改默认收藏内容，优先编辑 `docs/data.js`
- 如果浏览器里已经存在本地缓存，页面会优先使用缓存数据，而不是立即显示你改过的默认数据
- 如果发现修改 `docs/data.js` 后页面没有变化，可以先清除浏览器本地存储再重新打开页面
- 通过页面里的导出功能，可以把当前浏览器中的分类和链接导出成新的数据文件，方便回写或备份

仓库中虽然还有 `src/` 目录下的少量 React / TypeScript 文件，但从当前实现来看，实际主页入口和可发布内容仍然是 `docs/` 下的静态页面，这份 README 也以这一部分为准进行说明。
