## 设计

延续原站深色、绿色分类标题、粉色链接及密集网格，重新统一边框、字体、间距和按钮层级。Logo 加入终端提示符；分类旁展示当前显示的网址数量。加入轻微悬停、按压反馈和表单进入动效；遵循系统减少动态效果、减少透明度和增强对比度偏好。

手机采用双列链接，编辑按钮至少 44px，编辑表单采用底部面板。桌面可按 `/` 聚焦搜索；标签页重绘后保留键盘焦点。

仅修改 cloud/client/index.html、cloud.css、app.mjs；未更改云端数据库、登录配置、原 GitHub Pages 静态页或已有收藏。

## 第二轮：恢复原版霓虹风

用户认为原版更好看，可能与动效有关。对照 docs/style.css 后发现，原版包含 #00ff9d 荧光绿、大号绿色分类标题、绿色光晕悬停、主按钮扫光，第一轮均弱化了这些特点。

第二轮恢复上述色彩与交互，压缩介绍区，移除额外的终端图标和英文介绍文字。桌面公开页首组九个网址在默认 1470px 视口中排在同一行。保留可访问的页面标题、动态管理和手机双列布局。

验证：浏览器真实鼠标悬停后，链接颜色 rgb(0,255,157)、阴影 12px、上浮 2px；390px 视口无水平溢出；管理编辑面板开启与取消正常。该轮仅修改 HTML/CSS，git diff --check 通过，未重复运行未受影响的服务端测试。仍未发布。
